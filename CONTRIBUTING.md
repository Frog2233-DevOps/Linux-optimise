# Контрибуция

1. `make lint test` обязателен, CI гоняет то же самое плюс smoke.
2. Новая опция: флаг, строка в `usage`, строка в README, проверка в `run_checks`, если состояние можно проверить.
3. Всё, что трогает SSH или ufw, — внутри транзакции `SSH_TXN`.
4. Новый шаг — идемпотентный: повторный `apply` не должен ничего менять.
5. Коммиты в imperative, один смысловой блок на коммит.

Тесты: `tests/unit` (bats, через `BOOTSTRAP_LIB_ONLY=1`), `make smoke` (systemd-контейнер, реальный прогон).
